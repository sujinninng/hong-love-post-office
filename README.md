# 석범이와 수진이의 사랑 우체국

부모님께 드리는 생일 선물용 모바일 웹앱입니다. HTML, CSS, JavaScript 파일만으로 동작하고 빌드 과정이 없습니다.

## 파일 구성

```
index.html              앱 시작 파일 (저장소 맨 위에 둡니다)
css/style.css           화면 디자인
js/app.js               앱 동작
js/sound.js             배경음악·효과음 (파일 없이 브라우저에서 직접 합성)
data/messages.json      편지 (첫 편지 + 날짜별 편지)
data/config.json        특별한 날, 효도 쿠폰 목록
assets/img/             우체국, 캐릭터 등 그림
assets/photos/          편지에 붙일 사진 (지금 12장)
assets/icons/           홈 화면 아이콘
manifest.webmanifest    홈 화면에 추가할 때 쓰는 정보
.nojekyll               GitHub Pages가 파일을 그대로 올리게 하는 빈 파일
```

## 내 컴퓨터에서 먼저 열어 보기

`index.html`을 더블클릭하면 편지 파일을 읽지 못해 "다시 시도" 화면이 나옵니다. 이 폴더에서 아래 명령으로 작은 서버를 켜고 브라우저에서 `http://localhost:8000` 을 여세요.

```
python3 -m http.server 8000
```

## GitHub Pages에 올리기

1. github.com에서 새 저장소를 만듭니다. 이름은 영어로 (예: `love-post-office`). 무료 계정은 Public 저장소여야 Pages를 쓸 수 있습니다.
2. 이 폴더 안의 파일과 폴더를 전부 저장소 맨 위에 올립니다. (Add file → Upload files에 끌어다 놓기. `.nojekyll`처럼 점으로 시작하는 파일도 함께)
3. 저장소 Settings → Pages → Source를 "Deploy from a branch", Branch를 `main` / `/(root)`로 저장합니다.
4. 1~2분 뒤 `https://아이디.github.io/love-post-office/` 로 접속해 확인합니다.
5. 이 주소를 카카오톡으로 보내고, 부모님 휴대폰에서 연 뒤 "홈 화면에 추가"를 해 드립니다. 카카오톡 안에서 열렸다면 먼저 "다른 브라우저로 열기"로 사파리나 크롬에서 열어야 합니다.

## 편지 추가하기 (`data/messages.json`)

`messages` 목록에 아래 모양으로 한 통씩 추가합니다.

```json
{
  "id": "m006",
  "date": "2026-11-19",
  "from": "sujin",
  "courier": "sujin",
  "to": "어머님 아버님께",
  "text": "첫 줄\n둘째 줄",
  "photos": [
    { "src": "assets/photos/1119-family.jpg", "caption": "작년 가을 소풍" }
  ]
}
```

- `id`: 겹치지 않는 영어·숫자 이름. 한 번 정하면 바꾸지 마세요 (열어 본 기록이 id로 저장됩니다).
- `date`: 공개 날짜. 한국 시간으로 그날 0시부터 보입니다. 하루에 한 통, 날짜가 겹치면 뒤의 것은 무시됩니다.
- `from`: 쓴 사람. `seok`, `sujin`, `both` 중 하나. 편지 끝의 "○○ 올림"에 쓰입니다.
- `courier`: 배달원. `seok`, `sujin`, `both` 중 하나. 지우면 날짜와 id로 자동으로 정해지고, 어느 휴대폰에서나 같은 결과가 나옵니다.
- `to`: 편지 첫 줄의 받는 사람. 지우면 "엄마 아빠께".
- `text`: 본문. 줄을 바꾸려면 `\n`.
- `photos`: 0~3장. 사진이 없으면 `[]`.
- 날짜가 비는 날은 "새로운 사랑을 준비하고 있어요" 안내가 나옵니다. 지난 편지를 다시 새 편지처럼 보여 주지 않습니다.
- `welcome`은 첫 방문 이벤트 끝에 나오는 첫 편지입니다. 날짜와 상관없이 항상 볼 수 있습니다.
- `"draft": true`를 넣은 편지는 날짜가 되어도 부모님께 보이지 않습니다. 아직 확정하지 않은 편지를 미리 적어 둘 때 쓰고, 확정하면 그 줄을 지우세요.

쉼표나 따옴표가 하나만 틀려도 편지 전체를 못 읽습니다. 올리기 전에 jsonlint.com 같은 곳에 붙여 넣어 확인하세요.

## 사진 넣기

1. 사진을 `assets/photos/`에 넣습니다. 파일 이름은 영어·숫자로 (예: `1119-family.jpg`).
2. 긴 쪽이 1200px 정도가 되게 줄여서 올리면 빨리 뜹니다.
3. 편지의 `photos`에 `src`와 `caption`을 적습니다. 가로·세로 사진 모두 됩니다.
4. 사진을 바꿀 때는 같은 이름으로 덮어쓰지 말고 새 이름으로 올린 뒤 `src`를 고치세요. 같은 이름은 휴대폰에 예전 사진이 남아 보일 수 있습니다.

지금 12통에 사진이 한 장씩 붙어 있습니다. 올린 사진은 크기를 줄이고 위치정보(GPS)를 지운 것입니다. 새 사진도 위치정보를 지우고 올리세요. 사진이 없는 편지(`"photos": []`)는 편지지만 깔끔하게 보입니다.

## 소리

- 처음 화면을 누르는 순간부터 배경음악이 나옵니다(브라우저는 누르기 전에는 소리를 못 냅니다).
- 홈과 첫 방문 화면 오른쪽 위 스피커 버튼, 또는 설정에서 끌 수 있고, 끈 상태는 그 휴대폰에 기억됩니다.
- 아이폰은 옆면 무음 스위치가 켜져 있으면 소리가 나지 않습니다.
- 음악을 바꾸려면 `js/sound.js`의 `BARS`(멜로디)와 `BPM`(빠르기)을 고칩니다.

## 특별한 날과 쿠폰 (`data/config.json`)

- `specialDays`: 11월 21일(아버님 생신) 축하 화면은 켜져 있습니다. 11월 11일(어머님 생신) 화면은 `"draft": true`로 숨겨져 있으니, 내년 전에 문구(`headline`, `text`)를 확인하고 `"draft": true,` 줄을 지우세요. `date`는 `"11-21"`처럼 월-일. 그날 처음 열면 축하 화면이 한 번 뜨고, 홈에 다시 보는 버튼이 생깁니다. `photo`에 사진 경로를 넣으면 함께 보입니다.
- `coupons`: 효도 뽑기에서 나오는 쿠폰. `id`는 바꾸지 말고 `name`, `desc`를 고치거나 새 항목을 추가하세요.

## 다른 날짜 화면 미리 보기

- 주소 끝에 `?date=2026-11-17`을 붙이면 그 날짜로 보입니다.
- 또는 설정 화면 맨 아래 버전 글자를 5번 누르면 "미리보기 날짜" 칸이 나옵니다. 앱을 닫으면 원래대로 돌아갑니다.

## 올린 뒤 바뀐 내용이 반영되는 시간

- 편지와 설정(JSON)은 열 때마다 새로 받아옵니다.
- 디자인·동작 파일(css, js)과 그림은 최대 10분쯤 예전 것이 보일 수 있습니다.
- 서비스 워커는 넣지 않았습니다. 그래서 인터넷이 없으면 새 편지는 못 받지만, 마지막으로 받은 편지는 볼 수 있습니다.

## 개인정보 주의

- GitHub Pages 주소는 아는 사람 누구나 열 수 있습니다. 로그인이나 비밀번호로 막을 수 없습니다.
- 저장소가 Public이면 편지 내용과 사진 파일을 저장소에서도 누구나 볼 수 있고, 아직 공개 전인 미래 편지도 `messages.json`에 그대로 보입니다.
- 검색에 잘 걸리지 않도록 `noindex` 표시를 넣었지만 보장되지는 않습니다.
- 주소, 전화번호, 얼굴이 크게 나온 사진처럼 공개되면 곤란한 것은 넣지 마세요. 참고용으로 받은 사진은 이 폴더에 들어 있지 않습니다.

## 휴대폰에 저장되는 것

열어 본 편지 표시, 뽑은 쿠폰, 첫 방문 이벤트를 봤는지는 각 휴대폰 브라우저에만 저장됩니다. 두 분 휴대폰끼리 공유되지 않고, 브라우저 기록을 지우면 사라집니다. 사파리에서 본 것과 홈 화면에 추가한 앱도 기록이 따로일 수 있습니다.
